bkit / objex

objex

A backend-independent API for object storage.

objex defines the Bucket interface, optional capability interfaces, call options, key validation rules, and sentinel errors. Drivers live in their own modules, so an application installs only the driver it uses. Application code that depends on objex.Bucket switches backends by changing the one place the driver is constructed.

Usage

Writing and reading objects

Construct the driver in one place and pass objex.Bucket everywhere else.

Write and read objects / go 
func newStorage(ctx context.Context) (objex.Bucket, error) {
	client, err := s3.New(ctx, s3.WithRegion("us-east-1"))
	if err != nil {
		return nil, err
	}
	return client.Bucket("assets"), nil
}

func saveAvatar(ctx context.Context, b objex.Bucket, userID string, r io.Reader) error {
	_, err := b.Put(ctx, "avatars/"+userID+".png", r, objex.WithContentType("image/png"))
	return err
}
Read an object range / go 
obj, err := b.Get(ctx, "avatars/42.png")
if err != nil {
	return err
}
defer obj.Close()

head, err := b.Get(ctx, "videos/intro.mp4", objex.WithRange(0, 1<<20))
if err != nil {
	return err
}
defer head.Close()

Listing

List returns an iterator and fetches further pages as you range over it. WithDelimiter("/") groups keys into directory-like entries with IsPrefix set. WithStartAfter resumes after a key.

List objects / go 
for info, err := range b.List(ctx, objex.WithPrefix("avatars/")) {
	if err != nil {
		return err
	}
	fmt.Println(info.Key, info.Size, info.LastModified)
}

Conditional writes, copy, and move

Use IfNotExists to create only, or IfMatch with an ETag to replace only the version you read. objex.Move uses the driver's native move when available and falls back to copy-then-delete.

Conditional writes and copy / go 
_, err := b.Put(ctx, "locks/job-7", r, objex.IfNotExists())

info, _ := b.Stat(ctx, "config.json")
_, err = b.Put(ctx, "config.json", r, objex.IfMatch(info.ETag))
if errors.Is(err, objex.ErrPreconditionFailed) {
	// Another writer changed the object first.
}

info, err = b.Copy(ctx, "archive/report.pdf", "inbox/report.pdf")
info, err = objex.Move(ctx, b, "done/report.pdf", "inbox/report.pdf")
ok, err := objex.Exists(ctx, b, "done/report.pdf")

Capabilities and keys

Drivers implement optional interfaces when their backend supports them. Check with a type assertion on objex.Bucket: objex.Presigner for time-limited GET and PUT URLs, objex.Mover for native atomic moves, objex.Pinger to verify reachability, and objex.Manager on driver clients for bucket creation, deletion, and listing.

Presign object requests / go 
if p, ok := b.(objex.Presigner); ok {
	req, err := p.PresignGet(ctx, "avatars/42.png", 15*time.Minute)
}

Key and bucket rules

Every driver validates keys with objex.ValidateKey: valid UTF-8, 1 to 1024 bytes, /-separated segments that are non-empty and never . or .., with no backslashes or control characters. Bucket names follow objex.ValidateBucketName: 3 to 63 lowercase letters, digits, hyphens, and dots.

Errors

Failures are *objex.Error values carrying Op, Bucket, Key, a sentinel, and the underlying error. Match sentinels with errors.Is: ErrNotFound, ErrBucketNotFound, ErrBucketExists, ErrBucketNotEmpty, ErrPermission, ErrPreconditionFailed, ErrInvalidKey, ErrInvalidBucketName, ErrInvalidRange, ErrInvalidOption, and ErrUnsupported.

Sentinel Meaning
ErrNotFound The object does not exist
ErrBucketNotFound The bucket does not exist
ErrBucketExists A bucket being created already exists
ErrBucketNotEmpty A bucket being deleted still holds objects
ErrPermission The credentials do not allow the operation
ErrPreconditionFailed IfMatch or IfNotExists did not hold
ErrInvalidKey The key fails ValidateKey
ErrInvalidBucketName The name fails ValidateBucketName
ErrInvalidRange The range is malformed or starts past the end
ErrInvalidOption An option is malformed or conflicts with another
ErrUnsupported The driver cannot provide the operation or option
Inspect an object error / go 
var objexErr *objex.Error
if errors.As(err, &objexErr) {
	log.Printf("%s %s/%s failed: %v", objexErr.Op, objexErr.Bucket, objexErr.Key, objexErr.Err)
}

Driver setup

s3

Supports Amazon S3, MinIO, and Cloudflare R2. Small bodies upload in a single PutObject, and larger streams use multipart upload. Every operation on a missing bucket returns objex.ErrBucketNotFound.

client, err := s3.New(ctx,

	s3.WithEndpoint("https://objects.example.com"),
