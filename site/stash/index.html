bkit / stash

stash

One API over key-value stores.

Keep values in process memory, in the application's SQL database, or on a Redis or Valkey server, and switch between them by changing a URL or constructor. Every driver runs the stashtest conformance suite, so code written against *stash.Store behaves the same on all of them.

Usage

Opening a store

Pass the drivers the application supports to stash.Open, or pass an existing *rdb.DB to database.New.

Open a store by URL / go 
s, err := stash.Open(ctx, os.Getenv("STASH_URL"),
	memory.Driver(),
	redis.Driver(),
	valkey.Driver(),
)
if err != nil {
	return err
}
defer s.Close()

Typed values, locks, and counters

stash.Typed[T] encodes Go structs with a codec such as stash.JSON. IfNotExists() and Incr run atomically in the store.

Typed values and locks / go 
sessions := stash.Typed[Session](s.Namespace("sessions"), stash.JSON)
err := sessions.Set(ctx, sessionID, Session{UserID: 42}, stash.WithTTL(24*time.Hour))
sess, err := sessions.Get(ctx, sessionID)

err = s.Set(ctx, "lock:job-7", []byte(owner), stash.IfNotExists(), stash.WithTTL(30*time.Second))
if errors.Is(err, stash.ErrExists) {
	return ErrBusy
}

n, err := s.Incr(ctx, "signups:2026-11-14", 1)

Namespaces and expiry

s.Namespace("cache") prefixes keys with cache:, and cache.Clear(ctx) deletes only keys in that namespace (Clear on the root store fails with ErrInvalidOption). s.TTL(ctx, key) returns the remaining time or stash.NoExpiry, and s.Expire(ctx, key, ttl) updates or removes expiry.

Errors

Match *stash.Error values with errors.Is: ErrNotFound, ErrExists, ErrNotInteger, ErrInvalidKey, ErrInvalidOption, ErrCodec, ErrClosed, ErrUnknownDriver, and ErrInvalidURL. Error messages never contain the store URL, a key, or a value.

Sentinel Meaning
ErrNotFound The key is missing or expired
ErrExists IfNotExists found the key already set
ErrNotInteger Incr on a value that is not an integer, or an overflow
ErrInvalidKey An empty, non-UTF-8, or too long key or namespace
ErrInvalidOption A negative TTL, or Clear on the root store
ErrCodec A typed value the codec cannot encode or decode
ErrClosed A call after Close
ErrUnknownDriver No driver matches the URL's scheme
ErrInvalidURL The URL cannot be parsed or has no scheme

database

Stores keys in a SQL table created by database.New, with millisecond expiry precision. A TTL under a millisecond counts as one millisecond, and every hundredth write deletes expired rows.

API reference ↗ · View source ↗

Install stash database / shell 
go get github.com/brian-nunez/bkit/stash/drivers/database
database setup / go 
db, err := rdb.Open(ctx, os.Getenv("DATABASE_URL"),
	sqlite.Driver(),
	postgres.Driver(),
)
if err != nil {
	return err
}
defer db.Close()

s, err := database.New(ctx, db,
	database.WithTable("sessions"),
)
if err != nil {
	return err
}
defer s.Close()
