bkit / loom

loom

Graphs of typed Go functions, run in parallel on a worker pool you can grow and shrink while it runs.

A task is a plain function. loom starts each task as soon as its parents are done, passes their values in with their real types, and reports what happened. Retries, timeouts, and failure handling are options you set. loom never logs. Hooks report every event. It uses only the standard library and has no drivers.

Usage

Tasks and dependencies

Add puts a function in a graph and returns a typed handle. After declares the tasks it depends on, and Get reads their values. Every task has the shape func(ctx context.Context, in *loom.Inputs) (T, error). Graph mistakes, such as a duplicate name, a parent from another graph, or a cycle, fail Validate and Run before any task starts.

Run a task graph / go 
g := loom.New()
users := loom.Add(g, "users", fetchUsers)
orders := loom.Add(g, "orders", fetchOrders)
report := loom.Add(g, "report", func(ctx context.Context, in *loom.Inputs) (Report, error) {
	return build(loom.Get(in, users), loom.Get(in, orders)), nil
}, loom.After(users, orders))

res, err := g.Run(ctx)
if err != nil {
	return err
}
fmt.Println(loom.Get(res, report))

Named dependencies and results

AfterName declares parents by name, so a task can depend on a task added after it. Names resolve when the graph runs. Run returns a *loom.Result even when it fails, so res.State(task) and res.Err(task) are always available. A graph can run any number of times, concurrently.

Depend on a task by name / go 
var users *loom.Task[[]User]
count := loom.Add(g, "count", func(ctx context.Context, in *loom.Inputs) (int, error) {
	return len(loom.Get(in, users)), nil
}, loom.AfterName("users"))
users = loom.Add(g, "users", fetchUsers)

Failure handling

A trigger rule decides whether a task with parents runs once they are done. The default is AllSuccess. AllDone runs cleanup whatever happened, and Lookup reports whether a parent produced a value. Any func(parents []loom.State) bool is a trigger too.

Task StateMeaning
SucceededReturned a nil error
FailedReturned an error, panicked, or ran out of retries
SkippedReturned loom.ErrSkip, or its trigger rule declined without a failed parent
UpstreamFailedIts trigger rule declined because a parent failed
CanceledThe run's context ended, FailFast stopped the run, or the pool closed
TriggerRuns the Task When
loom.AllSuccessEvery parent succeeded (default)
loom.AllDoneEvery parent is done, whatever its state
loom.AllFailedEvery parent failed or was upstream-failed
loom.OneSuccessAt least one parent succeeded
loom.OneFailedAt least one parent failed or was upstream-failed
loom.NoneFailedNo parent failed or was upstream-failed
Run cleanup with AllDone / go 
loom.Add(g, "cleanup", func(ctx context.Context, in *loom.Inputs) (struct{}, error) {
	if files, ok := loom.Lookup(in, download); ok {
		removeAll(files.Paths)
	}
	return struct{}{}, nil
}, loom.After(download, upload), loom.WithTrigger(loom.AllDone))

Retries and resuming

Tasks are retried only by a policy you pass to WithRetry. The policy sees each failed attempt and returns a delay and whether to retry. loom.Backoff is a ready-made exponential backoff policy. loom.FailFast() stops a run at its first failure. loom.Resume(prev) reruns only the tasks that did not succeed or skip in an earlier result, and reuses the values of those that did.

Retry and resume / go 
policy := func(a loom.Attempt) (time.Duration, bool) {
	switch {
	case errors.Is(a.Err, loom.ErrInterrupted):
		return 0, true
	case errors.Is(a.Err, errBadInput):
		return 0, false
	default:
		return loom.Backoff(3, time.Second, 30*time.Second)(a)
	}
}
g := loom.New(loom.WithRetry(policy), loom.WithTimeout(time.Minute))

res, err := g.Run(ctx)
if err != nil {
	res, err = g.Run(ctx, loom.Resume(res))
}

Pools and hooks

Elastic worker pools

A pool is a set of workers that any number of graphs and runs share. Grow and Shrink change its size while it runs. With Interrupt, Shrink cancels the removed workers' tasks with the cause loom.ErrInterrupted, and the task's retry policy decides whether it runs again on another worker. Shrink to zero pauses the pool until Grow. Shutdown(ctx) stops the pool and gives running tasks until ctx ends to finish. Close is Shutdown with no deadline.

Resize a shared worker pool / go 
pool, err := loom.NewPool(loom.WithWorkers(4))
if err != nil {
	return err
}
defer pool.Close()

g := loom.New(loom.WithPool(pool))

pool.Grow(4)
pool.Shrink(2)
pool.Shrink(2, loom.Interrupt())

Hooks and untrusted task isolation

Hooks are callbacks for events. loom calls them in order on a separate goroutine, so a slow hook never delays a task. Every task, trigger, retry policy, and hook runs isolated on its own goroutine. A panic or runtime.Goexit in a task or trigger is recovered and reported as ErrPanic, and a failing hook is dropped.

Observe task events / go 
g := loom.New(loom.WithName("ingest"), loom.WithHooks(loom.Hooks{
	OnTaskFinish: func(ctx context.Context, e loom.TaskEvent) {
		slog.InfoContext(ctx, "task", "graph", e.Graph, "task", e.Task,
			"state", e.State, "attempt", e.Attempt, "err", e.Err)
	},
}))
HookCalled When
OnRunStart, OnRunFinishA run starts or returns (RunEvent)
OnTaskStartAn attempt starts on a worker (TaskEvent)
OnTaskRetryA failed attempt will run again (TaskEvent)
OnTaskFinishA task reaches a final state (TaskEvent)
OnWorkerStart, OnWorkerStopA worker joins or leaves a pool (WorkerEvent)
OnResizeGrow or Shrink changes a pool's size (ResizeEvent)

Errors

A task that does not succeed reports a *loom.Error with the task's name, the attempt, a Kind, and the task's own error. Run joins the errors of every failed task. Match them with errors.Is and errors.As. When the run's context ends, the error also matches context.Cause(ctx).

SentinelMeaning
ErrInvalidGraphA nil graph or function, an empty or duplicate name, a foreign or unknown parent, a cycle, or an Add after Run
ErrCycleTasks that depend on each other in a loop. Also matches ErrInvalidGraph
ErrInvalidOptionAn out-of-range option, a nil option or context, a foreign Resume result, or a pool not made by NewPool
ErrSkipReturned by a task to mark it Skipped
ErrUpstreamKind of a task whose trigger rule saw a failed parent
ErrTimeoutKind of an attempt that failed after its timeout
ErrPanicKind of an attempt or trigger that panicked or called runtime.Goexit
ErrInterruptedKind of an attempt that failed after its worker was interrupted
ErrClosedA pool call after Shutdown, or a task that could not start because its pool closed
ErrInvalidSizeA Grow or Shrink count below one, or a Shrink larger than the pool
ErrNestedRunA run inside a task on the same pool
Inspect a task error / go 
res, err := g.Run(ctx)
var e *loom.Error
if errors.As(err, &e) {
	log.Printf("task %s failed on attempt %d: %v", e.Task, e.Attempt, e.Err)
}
if errors.Is(err, loom.ErrTimeout) {
	// At least one task timed out.
}
