bkit

General-purpose Go modules, each versioned, released, and installed on its own.

Small, focused APIs with swappable drivers, so an application changes backends in one place. Every module uses the standard library first and reaches 100% test coverage.

01 / WHY BKIT

Why bkit

Independent

Every module has its own go.mod and release tags, so an application imports only the pieces it uses and upgrades each one separately.

Swappable

Modules with backends define one API, and each backend is a driver module. Changing a database, store, or bucket backend means changing the one place the driver is constructed.

Light

Core modules use only the standard library. Third-party client libraries live in driver modules, so an application installs only the clients it needs.

Tested

Every module reaches 100% statement coverage from its own tests, with no external services. objex and stash drivers also run a shared conformance suite, so they behave the same for the same calls.

Released

Versions follow Semantic Versioning and are cut automatically from Conventional Commits, one module at a time.

03 / QUICK START

Quick start

Modules compose cleanly. Here configuration comes from the environment, the database URL picks the SQL driver, and the key-value store shares the database connection pool.

Compose modules / go 
cfg, err := settings.Load(ctx, settings.Env(settings.WithPrefix("APP_")))
if err != nil {
	return err
}

db, err := rdb.Open(ctx, cfg.GetString("database.url", "sqlite:app.db"),
	sqlite.Driver(),
	rdb.WithMaxOpenConns(10),
)
if err != nil {
	return err
}
defer db.Close()

store, err := database.New(ctx, db)
if err != nil {
	return err
}

The URL scheme picks one driver, and only that driver connects. Setting APP_DATABASE__URL=postgres://... switches the same binary to PostgreSQL once postgres.Driver() is passed to rdb.Open.

gate

Any func(T) bool is a rule, and rules combine into larger ones.

gate example / go 
type rule = gate.Rule[Access]

func hasRole(role string) rule {
	return func(a Access) bool { return slices.Contains(a.User.Roles, role) }
}

var (
	isOwner  rule = func(a Access) bool { return a.User.ID == a.Doc.OwnerID }
	isBanned rule = func(a Access) bool { return a.User.Banned }

	canDelete = hasRole("admin").Or(hasRole("user").And(isOwner))
	canEdit   = canDelete.And(gate.None(isBanned))
)

if !canDelete(Access{User: user, Doc: doc}) {
	return ErrForbidden
}

loom

Tasks are plain functions with typed values. Each starts as soon as its parents are done.

Run a loom task graph / go 
g := loom.New(loom.WithRetry(loom.Backoff(3, time.Second, time.Minute)))
users := loom.Add(g, "users", fetchUsers)
orders := loom.Add(g, "orders", fetchOrders)
report := loom.Add(g, "report", func(ctx context.Context, in *loom.Inputs) (Report, error) {
	return build(loom.Get(in, users), loom.Get(in, orders)), nil
}, loom.After(users, orders))

res, err := g.Run(ctx)
if err != nil {
	return err
}
fmt.Println(loom.Get(res, report))

rdb

Write ? placeholders on every database, and scan rows into structs.

rdb example / go 
db, err := rdb.Open(ctx, os.Getenv("DATABASE_URL"), sqlite.Driver(), postgres.Driver())
if err != nil {
	return err
}

user, err := rdb.One[User](ctx, db, "SELECT id, email, created_at FROM users WHERE email = ?", email)
if errors.Is(err, rdb.ErrNotFound) {
	return ErrNoSuchUser
}

_, err = db.Exec(ctx, "INSERT INTO users (email) VALUES (?)", email)
if errors.Is(err, rdb.ErrUniqueViolation) {
	return ErrEmailTaken
}

err = db.Tx(ctx, func(tx *rdb.Tx) error {
	_, err := tx.Exec(ctx, "UPDATE accounts SET balance = balance - ? WHERE id = ?", amount, from)
	return err
})

stash

Store typed values with expiry, and take locks that one caller wins.

stash example / go 
s, err := stash.Open(ctx, os.Getenv("STASH_URL"), memory.Driver(), valkey.Driver())
if err != nil {
	return err
}

sessions := stash.Typed[Session](s.Namespace("sessions"), stash.JSON)
err = sessions.Set(ctx, sessionID, Session{UserID: 42}, stash.WithTTL(24*time.Hour))

err = s.Set(ctx, "lock:job-7", []byte(owner), stash.IfNotExists(), stash.WithTTL(30*time.Second))
if errors.Is(err, stash.ErrExists) {
	return ErrBusy
}

05 / VERSIONING AND QUALITY

Versioning and quality

Every module follows Semantic Versioning with tags of the form <module>/vX.Y.Z, or <module>/drivers/<driver>/vX.Y.Z for a driver. Releases are cut automatically from Conventional Commits, and only modules with releasing commits get a new version. Every module reaches 100% statement coverage from its own tests without external services.
