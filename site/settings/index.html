bkit / settings

settings

Load configuration from files, environment variables, remote stores, and code, and merge it into one tree.

Each source returns a tree of values. A format turns bytes into a tree, so any source that reads bytes works with any format. JSON, files, fs.FS, environment variables, and maps are built into the parent module. Other formats and remote stores live in driver modules.

Sources and drivers

Component Install / Call Description
Built-in Sources settings.File, settings.FileFS, settings.Env, settings.Map Read disk files, embed.FS files, environment variables, and in-code maps. settings.JSON is built in.
yaml go get github.com/brian-nunez/bkit/settings/drivers/yaml yaml.Format decodes YAML bytes into a settings tree for settings.File, settings.FileFS, or consul.Client.Key.
toml go get github.com/brian-nunez/bkit/settings/drivers/toml toml.Format decodes TOML bytes into a settings tree for settings.File, settings.FileFS, or consul.Client.Key.
vault go get github.com/brian-nunez/bkit/settings/drivers/vault Reads HashiCorp Vault key-value secrets over HTTP using the standard library.
consul go get github.com/brian-nunez/bkit/settings/drivers/consul Reads single formatted keys or key prefixes from HashiCorp Consul over HTTP using the standard library.

Usage

Load applies sources from left to right, and the later source wins. Two maps merge key by key. All keys and lookup paths are lowercased and joined with dots. settings.Env splits nested keys on a double underscore (__), so APP_SERVER__PORT=8080 with WithPrefix("APP_") sets server.port.

Load and read configuration / go 
cfg, err := settings.Load(ctx,
	settings.Map(map[string]any{"server": map[string]any{"addr": ":80"}}),
	settings.File("config.yaml", yaml.Format),
	settings.Env(settings.WithPrefix("APP_")),
)
if err != nil {
	return err
}

addr := cfg.GetString("server.addr", ":8080")
port, err := settings.Get[int](cfg, "server.port")

var app AppConfig
err = cfg.Decode(&app)

Reading methods

cfg.GetString, GetInt, GetBool, GetFloat, and GetDuration return the default passed in when a key is missing or has the wrong type. settings.Get[T](cfg, path) returns settings.ErrNotFound or settings.ErrType. cfg.Decode(&target) fills a struct by settings:"name" tag or field name, or merges into a map with string keys while keeping existing entries and merging nested maps key by key. JSON integers beyond int64 read as uint64. Integers beyond uint64 remain decimal strings and can be read as strings or converted to float64.

Errors

Parent sentinels are settings.ErrNotFound, settings.ErrType, and settings.ErrParse. A conversion error names the key path and the value's type, and never includes the value, so a secret read as the wrong type stays out of logs. Messages omit error text from encoding.TextUnmarshaler. The Vault and Consul drivers also provide ErrNotFound, ErrPermission, ErrResponse, and ErrInvalidAddress, and never include tokens in error messages.

Sentinel Meaning
settings.ErrNotFound No value exists at the path
settings.ErrType The value cannot be converted to the requested type
settings.ErrParse A format could not parse a document

vault

Calls Vault over HTTP with the standard library. Supports client.KV2(mount, path), vault.WithVersion(n), client.KV1(mount, path), vault.WithToken, vault.WithNamespace, and vault.WithHTTPClient. With a token set, redirects to another host or from https to http are not followed and fail with vault.ErrResponse. A custom CheckRedirect on the client passed to vault.WithHTTPClient sets the redirect policy.

API reference ↗ · View source ↗

Install settings vault / shell 
go get github.com/brian-nunez/bkit/settings/drivers/vault
vault setup / go 
client, err := vault.New("https://vault.example.com:8200",
	vault.WithToken(token),
)
if err != nil {
	return err
}

cfg, err := settings.Load(ctx,
	settings.File("config.yaml", yaml.Format),
	client.KV2("secret", "apps/web"),
)

consul

Calls Consul over HTTP with the standard library. client.Key(key, format) parses a single document with any format, and client.Prefix(prefix) reads every key under a prefix into nested keys. With a token set, redirects to another host or from https to http are not followed and fail with consul.ErrResponse. A custom CheckRedirect on the client passed to consul.WithHTTPClient sets the redirect policy.
